# Support Information 🛠️ (HYDRA-UMC-DEVELOPER-NODE)

Thank you for using HYDRA-UMC-DEVELOPER-NODE! Here is how you can get help:

## 📺 Video Tutorials & Demos

Our official YouTube channel: [youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries

For questions about the configuration, the approvals or anything not covered by the README: Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports

If `hydra-umc-developer-node evidence verify` accepts a bundle it should refuse (or the reverse), if a run starts without an approval, or if the checkout cache keeps more than its limit, please open a **GitHub Issue** in this repository - include the exact command, the configuration (without any secret) and the full output. *Please search existing issues before opening a new one.*

## ❌ What is NOT support?

- This node studies failures and reproduces them; it does not apply fixes, push to repositories or run on its own. Please do not open an Issue asking it to repair a real system.
- A bug inside a project it works with (HYDRA-UMC-LOCAL-TECHNICIAN, HYDRA-UMC-SDK, HYDRA-UMC-OPS-AGENT, ...) belongs on that project's own issue tracker.
